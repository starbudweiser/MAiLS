# DESIGN SYSTEM & CHARTE GRAPHIQUE — CLIENT MAIL FLAT MACOS

## 1. Règles absolues
- Zéro transparence / zéro flou (`Material`, `NSVisualEffectView` interdits).
- Zéro ombre portée (`shadow`), zéro dégradé (`LinearGradient`).
- Surfaces 100 % mates séparées par des traits nets de `1px`.
